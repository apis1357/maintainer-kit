# Security Policy

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub private vulnerability reporting when it is available for this repository. If it is unavailable, open a minimal issue requesting a private contact channel without including vulnerability details.

Include reproduction details, impact, affected versions, and any suggested mitigation in the private report.

Maintainer Kit does not make network requests or execute files from the repository being audited. Checks are based on filesystem metadata and file presence.
